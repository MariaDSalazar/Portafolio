# Portafolio

Portafolio personal migrado a Next.js 15 con TypeScript y App Router.

## Stack

- Next.js 15
- React 19
- TypeScript
- CSS global

## Scripts

- `npm run dev`: inicia el entorno de desarrollo
- `npm run build`: genera la build de producción
- `npm run start`: levanta la build de producción
- `npm run lint`: ejecuta ESLint

## Estructura principal

- `app/layout.tsx`: layout global y metadata
- `app/page.tsx`: landing principal
- `app/globals.css`: estilos globales
- `public/`: imágenes y assets estáticos

## Notas

La migración conserva la apariencia general del sitio original, pero corrige navegación, responsive y accesibilidad básica.
